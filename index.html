1. 처리 목적과 범위

이 확장은 영상 자막·문서를 번역하고 학습 자료로 정리하는 단일 목적을 위해 정보를 처리합니다. 기능을 켜 둔 사이트에서 영상과 자막을 감지할 수 있으며, 사용자가 선택한 콘텐츠에 번역·요약·질문·하이라이트·주석·문서 저장 기능을 제공합니다.

음성 인식은 사용자가 직접 시작한 경우 해당 탭의 소리를 처리합니다. 마이크를 자동으로 녹음하지 않습니다. 로그인이나 사이트의 콘텐츠 접근 제한을 우회하는 기능은 제공하지 않습니다.

2. 처리하는 정보

처리 항목은 사용하는 기능과 선택한 연결 방식에 따라 달라집니다. 기기 안에서만 처리하는 정보도 포함해 설명합니다.

  • 콘텐츠와 학습 정보: 영상 제목·주소·자막 텍스트·자막 시간, 사용자가 선택한 문서의 텍스트, 번역 결과, 모델에 보낸 질문과 답변, 하이라이트·주석·메모를 처리합니다. 음성 인식을 시작하면 탭의 음성 데이터도 처리합니다.
  • 선택한 영상의 이용 기록: 학습 화면에 선택한 영상의 제목·주소·시각 정보를 보관할 수 있습니다. 브라우저 전체 방문 기록을 수집하는 기능은 아닙니다.
  • 기능 동작과 성능 정보: 자막 요청·응답과 재생 상태를 감지하고, 모델 추천을 위한 성능 측정값을 기기 안에 보관할 수 있습니다. 일반적인 키 입력이나 다른 사이트의 모든 활동을 기록하지 않습니다.
  • 인증과 계정 정보: 사용자가 등록한 모델 접근 키와 문서 전송용 접근 토큰을 처리합니다. 맥 연결 프로그램으로 계정을 연결하면 해당 연결에 필요한 토큰, 이메일 주소, 계정 식별자를 처리할 수 있습니다. 기존 브라우저 쿠키나 다른 앱의 인증 파일을 가져오지 않습니다.
  • 설정과 선택 사양: 모델·언어·자막 표시·용어집·음성 인식·저장 방식 설정을 보관합니다. 사용자가 선택 사양 권한을 허용하면 프로세서와 메모리 정보를 음성 모델 추천에 사용할 수 있습니다.

건강 정보, 금융·카드·결제 정보, 정확한 위치를 조회하거나 보관하는 전용 기능은 없습니다. 다만 사용자가 직접 선택한 콘텐츠나 질문에 그러한 정보가 포함돼 있으면 선택한 번역·학습 기능에서 해당 텍스트가 처리될 수 있습니다.

3. 외부 연결과 정보 전달

번역·요약·질문 모델

모델을 선택해 기능을 실행하면 필요한 자막·문서 텍스트, 번역 언어·지시·용어집, 분석할 자막·질문·최근 대화가 해당 제공자에 전달될 수 있습니다. 등록한 접근 키는 연결하도록 설정한 서버 출처에 사용합니다.

Ollama·LM Studio 같은 로컬 주소에 연결할 수 있고, OpenAI·OpenRouter 또는 사용자가 등록한 호환 서비스 같은 외부 제공자에 연결할 수도 있습니다. 로컬 주소의 서버가 다시 클라우드 모델을 호출하는 경우 기기 밖에서 처리될 수 있으므로 주소가 로컬이라는 이유만으로 외부 전송이 없다고 보장하지 않습니다.

모델 제공자의 이용 한도, 보관·삭제·학습 사용 여부는 해당 제공자의 정책과 계정 설정에 따릅니다. 개인 주석을 모델에 자동으로 보내지 않지만, 사용자가 외부 저장소로 보내는 학습 문서에 주석·메모를 포함하면 그 내용도 함께 전달됩니다.

음성 인식

현재 음성 인식 연결은 로컬 음성 인식 서버를 사용하는 방식입니다. 사용자가 음성 인식을 시작하면 해당 탭의 소리를 선택한 로컬 연결에 전달합니다. 서버의 추가 처리나 보관 방식은 사용자가 설치·운영하는 서버 설정에 따라 달라질 수 있습니다.

옵시디언·노션·구글 드라이브

사용자가 대상과 미리보기 내용을 확인하고 전송에 동의하면 지정한 옵시디언 보관함에 새 파일을 만들거나 노션·구글 드라이브에 새 페이지·문서를 만들 수 있습니다. 외부 서비스에는 사용자가 선택한 학습 문서와 저장에 필요한 정보가 전달됩니다. 저장 이후의 접근·보관·삭제는 해당 서비스와 사용자 설정에 따릅니다.

구글 드라이브 전송용 접근 토큰은 사용자가 별도로 발급해 저장할 때마다 입력합니다. 현재 확장 자체에서 Google 로그인이나 토큰 발급을 제공하지 않습니다. 입력 토큰은 확장 설정이나 기록에 저장하지 않고 전송 후 입력값을 비웁니다. 이는 토큰 자체를 자동 폐기하거나 제공자에서 취소한다는 뜻은 아닙니다.

유튜브 외부 재생기

학습 화면에서 사용자가 영상 불러오기를 누르면 선택한 영상 식별자가 포함된 youtube-nocookie.com 외부 재생기에 연결합니다. 이때 외부 재생기의 네트워크 요청과 정보 처리는 Google 개인정보처리방침 및 브라우저 설정에도 따릅니다. 외부 재생기를 불러오지 않고 원본 영상 탭에서 재생하며 학습 화면을 사용할 수도 있습니다.

확장의 자체 프로그램 파일은 배포 패키지에 포함됩니다. 모델의 응답은 번역·분석 데이터로 처리하며 실행 코드로 평가하지 않습니다. 외부 재생기는 별도 서비스의 페이지이므로 자체 프로그램 파일과 구분됩니다.

4. 보관 위치와 기간

  • Chrome 동기화 저장소: 번역·표시 설정과 용어집을 보관합니다. 사용자가 Chrome 동기화를 켜면 브라우저 계정 설정에 따라 동기화될 수 있습니다.
  • Chrome 프로필의 로컬 저장소: 서버 출처별 모델 접근 키, 번역 캐시, 음성 인식 설정, 허용된 기기 사양과 성능 측정값을 보관할 수 있습니다.
  • 브라우저 세션 저장소: 질문·답변과 주석을 포함한 학습 노트 사본을 보관합니다. 영구 백업이 아니므로 필요한 문서는 별도로 저장해야 합니다.
  • 브라우저의 IndexedDB: 지원되는 폴더 저장 방식에서 사용자가 고른 저장 폴더 정보와 파일 접근 핸들을 보관할 수 있습니다.
  • 맥 연결 프로그램: 연결에 필요한 계정 정보와 로그인 토큰을 앱 전용 로컬 파일에 보관합니다. 공식 노션 명령줄 도구의 로그인 상태는 해당 도구가 관리합니다.
  • 파일·외부 서비스: 다운로드한 문서는 사용자가 고른 파일 위치에, 전송한 문서는 선택한 외부 서비스에 남습니다.

보관 기간은 저장소의 수명과 사용자의 삭제·계정 설정에 따라 달라집니다. 브라우저 저장 항목과 별도 설치한 연결 프로그램의 데이터는 각각 관리해야 하며, 확장을 제거해도 다운로드한 파일이나 외부 서비스에 저장한 문서까지 자동으로 삭제되지는 않습니다.

5. 사용자 제어와 삭제

해당 화면에서 사이트 기능을 끄거나 음성 인식을 중지하고, 모델 설정·접근 키를 변경하거나 계정에서 로그아웃할 수 있습니다. 프로세서·메모리 정보 권한은 기본 자막 번역에 필수적이지 않습니다.

맥 연결 프로그램에서 로그아웃하면 로그인 토큰을 지우지만 등록 이메일과 계정 식별자가 남을 수 있습니다. 계정 정보까지 모두 제거하려면 연결 프로그램의 앱 데이터도 별도로 관리해야 합니다. 제공자에서 접근 권한이나 토큰을 취소하려면 해당 제공자의 계정 관리 화면을 이용해야 합니다.

다운로드한 파일은 파일 시스템에서, 외부에 저장한 문서는 해당 서비스에서 사용자가 관리·삭제합니다. 저장 폴더 접근 권한과 브라우저 프로필의 저장 데이터도 브라우저 설정에서 별도로 관리할 수 있습니다. 기기에만 저장된 파일과 데이터에 게시자가 원격으로 접근해 대신 삭제하는 기능은 없습니다.

6. 목적 외 사용 제한

본 확장은 번역, 자막·문서 학습, 사용자 요청에 따른 문서 저장이라는 단일 목적에 필요한 범위에서 사용자 데이터를 사용합니다. Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

기능 제공과 관계없는 목적으로 사용자 데이터를 판매·사용·전송하지 않으며, 광고 목적이나 신용도 평가·대출 판단에 사용하지 않습니다. 사용자가 선택한 모델 제공자와 저장 서비스에 전달되는 정보는 기능 수행에 필요한 범위이며, 해당 제공자의 처리방침과 계정 설정도 함께 적용됩니다.

7. 이 정책 웹페이지의 호스팅

정책 웹페이지는 GitHub Pages에서 제공합니다. 이 페이지 자체에는 분석 도구, 광고, 추적용 스크립트, 입력 폼이나 외부 글꼴을 포함하지 않습니다. 다만 GitHub는 GitHub Pages 방문자의 인터넷 주소를 보안 목적으로 기록할 수 있습니다. 호스팅 제공자의 처리는 GitHub 개인정보처리방침에 따릅니다.

8. 문의와 정책 변경

정책 설명과 데이터 삭제 방법 등 일반 문의는 정책 저장소의 GitHub Issues에서 접수합니다. 게시자는 이 경로를 통해 문의에 답변합니다.

GitHub Issues는 누구나 볼 수 있는 공개 게시판입니다. 접근 키·로그인 토큰·이메일 주소·계정 식별자·개인 문서 원문·민감한 개인정보를 올리지 마세요. 문의할 때는 개인정보를 제거한 기능명과 증상을 적어 주세요. 모델 제공자나 외부 저장 서비스가 보관하는 데이터의 삭제 요청은 해당 서비스의 계정 관리·지원 경로를 이용해 주세요.

처리 항목이나 연결 방식이 바뀌면 이 정책과 제품 내 안내를 갱신하고 시행일을 변경합니다.
